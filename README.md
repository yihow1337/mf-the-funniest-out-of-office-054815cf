One out-of-office auto-reply, 136 characters, that keeps every organ of a real one — return date, escalation contact, stock phrasing — and hides the joke inside the format instead of replacing it. It escalates in four flat beats: your cover isn't staff, she was a stranger at a bus stop this morning, and the sender is assured of her completely. `main.py` reads the line from `entry.txt` and writes it to the output directory as UTF-8 with no trailing newline, so every run emits identical bytes.

## Run it

```sh
python3 main.py
```
